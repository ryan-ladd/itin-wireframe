Stop card decisions

Every choice made about how a stop looks as a card, what shows when you tap it, and what you can edit, across all 22 stop types, plus the Add a stop form.

The working reference is the brand guide, brand.html, under Components: Stop card, Stop anatomy and the Create form at the top of Stop anatomy. Pick any stop there to see its card, peek and edit views side by side. Everything below describes that page. The sample content in it (Georgian places, names, confirmation numbers) is made up.

The three views

Card

What you see in the itinerary list. Kept to a time and type line, a title, and at most one extra line or badge.

Peek

Opens when you tap a card. Read only. Shows every field that has been filled in and hides empty ones. Related fields share a row (date next to time, airline next to flight number).

Edit

Every field for that stop, in a fixed order. Opens from Edit in the peek. The Stop type dropdown at the top lets you switch the kind of stop and carries matching values across.

Rules that apply to every stop

Wording

  • We say stop for these symbols, cards and categories. The word “element” is retired.
  • Names settled on: Stay (was Accommodation, and its first field is Stay Type), Coffee (was Coffee Shop), Shop (was Store), Event (was Ticket), Car (not Car Rental), Miscellaneous.
  • Dates are written out: October 26, 2026.
  • Time zones are not shown anywhere.
  • In peek the label reads Confirmation. In edit it reads Confirmation Number.

Card

  • Top line is always time · type at the top left. The type can be more specific than the stop name (Dinner, Wine Bar, Market, Yoga).
  • The star (favorite) is always at the top right. Its top lines up with the top of the text, with an equal gap to the top and right edges.
  • No tags along the bottom, and no addresses on cards, except Stay and Car, which show one under the name.
  • One universal checkbox, Booked, is used on every stop that can be booked (Restaurant, Bar, Museum, Experience, Event, Wellness, Workout, Funicular, Miscellaneous, Bus, Train, Ferry). When it is checked the card shows a solid accent-colored Booked pill. When it is not, there is no pill.
  • Wellness and Workout have an optional Name. With a name, the name is the title and the location is the third line. Without one, the location is the title. Funicular has no name field.
  • Miscellaneous shows only the time at the top, with no type word beside it.

Edit and Create forms

  • A * marks a field that must be filled in to add any stop. A Date is always required, because every stop has to sort into a day. The Create form says so under its fields.
  • Fields show no placeholder or example text.
  • The order at the bottom is always Link, Photos, Notes.
  • A search field is a geosearch with a magnifier icon. The Address under it is filled from the result and is read only.
  • Checkboxes use the same spacing everywhere, matching the Restaurant checkboxes.
  • The Stop type dropdown shows each stop’s icon in a black rounded square with the drawing centered and equal padding on all sides.
  • Long dropdown lists scroll. The guide has a “Dropdown options” button that shows or hides the lists for review.

Peek icons

  • Maps icon on location fields (opens the place).
  • Copy icon on Address and Confirmation.
  • Phone icon on phone numbers (Stay).
  • Open link icon on Link, with no “Open link” text.
  • Tight spacing between each label and its value.

Behaviours

Add a stop (Create form)

  • The form opens with one dropdown under the heading Add a stop. The placeholder reads “Select”. There are no red outlines in this form.
  • The dropdown has a search box. It matches the stop names and related words, so “massage” finds Wellness, “beer” finds Bar, “gym” finds Workout, “hotel” finds Stay, “concert” finds Event. No match shows “No matching stop”.
  • Choosing a stop reveals that stop’s fields, blank, with Cancel and Add buttons. Choosing another swaps the fields.

Switching stop type in Edit

  • A field that exists in both stops keeps its value. The rest are dropped.
  • Common fields always carry over: time, star, link, confirmation number, notes.

Nested stops (Neighborhood and Drive)

  • The Edit view has a Stops list of connected stops. Each has a remove × button.
  • + Add stop opens a menu below the button with a search box. It lists stops not yet connected.
  • If nothing matches, the menu offers Create “what you typed”. That adds a Miscellaneous stop with that name and no time.
  • On the card the stops sit inside the parent card. The Hide Stops / Show Stops pill collapses them.

Transit cards (Bus, Train, Ferry)

  • The title shows origin area → origin area with the same short thin arrow as Flight.
  • Nobody types these two short place names. Take them from the pickup and drop-off search results: use the neighborhood if the result has one (Ortachala), otherwise the town (Sighnaghi).
  • Operator and number sit under the title as one line with no dot (“Georgian Bus 45”).

Decided after review

One checkbox name: Booked.It replaces Reservation (Restaurant, Bar), Ticket (Museum) and Booking (Experience). The same word is the badge on the card.
Miscellaneous.The Booked badge shows only when the box is checked. The word “Miscellaneous” is removed from beside the time.
Bottom of every form is Link, Photos, Notes.Visit, Wellness and Workout were out of order and are fixed.
Required fields.Date is required on every stop. The fields marked with an asterisk are the ones that must be filled in before a stop can be added.
Stay Type.The first field on Stay is now Stay Type (it was Accommodation Type).
Names on Wellness and Workout.Both get an optional Name field. Funicular does not.
The prototype.The clickable itinerary now uses the same wording: Stay, Coffee, Shop, Event, Stay Type, and “stop” in place of “element”. Its field sets and icon set have not been rebuilt to match the guide.
